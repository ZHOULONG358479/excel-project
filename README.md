# excel-project

> 使用 Python 自动化处理 Excel 中的重复性日期与工作表操作  
> 面向实际办公场景的轻量级自动化脚本项目

---

## 📌 项目背景

在日常工作中，经常需要 **每天对固定格式的 Excel 文件做重复操作**，例如：

- 按当天日期重命名文件
- 复制前一天工作表并以当天日期命名
- 修改表头中括号内的日期
- 保持原有公式、样式不变

这些操作**规则明确、重复度高、但极易出错**，因此本项目尝试使用 Python 进行自动化处理，  
以减少人工操作、提升效率与稳定性。

---

## 🎯 项目目标

- 用 **最少依赖** 完成 Excel 自动化
- 脚本可直接在本地一键运行
- 面向「真实办公需求」，而非教学示例

---

## ⚙️ 当前实现功能（v1）

已实现功能包括：

- ✅ 使用 `glob` 匹配指定前缀的 Excel 文件
- ✅ 自动按当天日期重命名 Excel 文件
- ✅ 复制最后一个工作表，并命名为当天日期（`YYYYMMDD`）
  - 若当天工作表已存在，则删除并重新生成
- ✅ 修改表头（A1 单元格）中括号内的日期
- ✅ 基于 `openpyxl` 实现，保持原有格式与公式
- ✅ 支持在 macOS 上通过 `.command` / `.app` 方式一键执行
