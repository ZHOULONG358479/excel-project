# Excel Project

一个用于 Excel 自动化处理的 Python 项目。  
适用于日常办公自动化任务，如文件重命名、工作表复制、表头修改等。

## 目录结构

excel-project/
├─ excel_project/ # Python 包
│ └─ main.py # 主脚本
├─ tests/ # 测试脚本
│ └─ test_main.py
├─ README.md
├─ requirements.txt
└─ .gitignore

## 使用方法

1. 安装依赖：
```bash
pip install -r requirements.txt
2.运行主脚本
python -m excel_project.main
开发指南
所有主代码放在 excel_project/
测试代码放在 tests/
遵循 PEP8 编码规范
贡献指南
如果你对本项目有改进或优化，欢迎 fork 并提交 PR。
在提交代码前，请确保通过测试脚本验证功能。
